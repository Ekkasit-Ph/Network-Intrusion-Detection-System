The Live tab answers what is arriving. This answers what is going on, which is a shorter list. A sweep is one decision and four hundred flows; grouping them back together is the difference between a console someone reads and one they stop reading. Every anomalous flow appears in exactly one incident — nothing is dropped, nothing counted twice.

The pattern names describe shape, not attack type. The detector produces one reconstruction error per flow and no class — it has no notion of “this is a DDoS”. fan-out means one source reached many destinations, which is what a port scan looks like and also what a monitoring agent looks like. Deciding which is a human judgement; this tab only groups the flows that belong together and puts the worst one in reach.
